# Stage RolTech — GMAO Simplifiée

Documentation du stage réalisé chez **Roller Technology Systems Industry**.

## Sujet

Conception et développement d'une application web de supervision et de
maintenance des machines industrielles (GMAO simplifiée).

## Contexte

Le suivi de l'état des équipements, des pannes et des interventions de
maintenance est actuellement géré manuellement (papier, Excel), entraînant
une perte de traçabilité et des retards dans la prise de décision.

## Objectifs

1. Recenser le parc machines (fiches techniques, historique)
2. Enregistrer les pannes et interventions (préventives et curatives)
3. Suivre l'état de chaque machine (en service, en panne, en maintenance)
4. Générer des tableaux de bord (indicateurs de disponibilité, fréquence des pannes)
5. Gérer les utilisateurs (techniciens, responsables) avec authentification et rôles

## Stack technique

- **Backend** : Symfony (PHP)
- **Base de données** : MySQL
- **Versioning** : Git
