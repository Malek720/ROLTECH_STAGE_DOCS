# Stage RolTech — GMAO Simplifiée

Documentation du stage réalisé chez Roller Technology Systems Industry.
Générée avec [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Aperçu local

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
mkdocs serve
```

Ouvre http://127.0.0.1:8000

## Déploiement

Le push sur `main` déclenche automatiquement le déploiement sur GitHub Pages
via `.github/workflows/deploy.yml`.
